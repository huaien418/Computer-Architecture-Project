# Contributions

This repository presents the scalar and RISC-V RVV work of GitHub user `huaien418` from a two-person Computer Architecture course project.

- Part 1: scalar DCT and inverse DCT baseline.
- Part 2: RVV vector reduction implementation and analysis.
- Part 3: RVV accumulation across independent outputs and analysis.

The original team project also included CUDA Parts 4–5, implemented by the teammate. Those source files and GPU performance claims are outside the personal implementation scope presented here.

The contribution boundary was confirmed by the author on 2026-10-19. Student IDs, the teammate's personal details and the original team report are omitted from this presentation copy.
