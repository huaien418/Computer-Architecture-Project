# Benchmark input

The formal archived benchmark used a 5184 x 3456 P5 grayscale image, comprising 279,936 8 x 8 blocks.

Input SHA-256: `a8baf05ce341da86dd0249eaca7a122036ca1cfb584dfbd4194a83396ff153b6`.

The original photo and full-size PGM files are retained in the separate original submission backup. They are not bundled in this presentation copy. The saved-image checks document comparisons performed against that original input and its archived reconstructions.

Reproducing those exact full-image statistics requires the same input, simulator setup and commands. A future small sample should have separate results and must not be presented as the original full-image benchmark.

This presentation copy still contains the original Makefiles; their old P1/P2/P3 paths require a separate reproducibility update. The privacy cleanup did not change program behavior or build paths.
